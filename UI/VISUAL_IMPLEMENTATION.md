## 2026-09-26 UI 레이어·글꼴 반영

- `UI/DeltaDotumKR.ttf`를 `src/assets/DeltaDotumKR.ttf`로 앱 번들에 포함하고 `Life Flow Delta` 웹 글꼴로 등록했다.
- 이 글꼴은 제목, 날짜, 시간대, 블록 번호, 작은 안내, 상태 레이블, 버튼처럼 짧고 장식적인 텍스트에만 적용했다.
- 카드 이름과 입력 내용은 기존 가독성 높은 한글 UI 글꼴을 유지했다.
- 새 레이어의 색 의미를 반영했다: 카드 hover는 연노랑, 현재 선택은 하늘색 테두리, 완료 버튼은 분홍, 메뉴는 하늘색 창 테두리다.
- `현재선택테두리.png`, `투두에마우스올린거.png`, `완료버튼.png`, `우클릭체크시팝업.png`는 각 상태의 시각 기준으로 사용했다. 반응형 카드와 마우스·키보드 조작을 유지하기 위해 동일한 형태를 CSS로 재구성했다.

- 카드 선택, 완료, 건너뜀, 드롭 위치, 버튼 누름에 120–180ms 범위의 짧은 피드백을 추가했다.

## 2026-09-26 PNG 레이어 직접 적용

- `기본배경.png`, `상단타이틀.png`, `칸.png`, `메모 마스킹 테이프.png`, `하단 줄.png`를 투명 레이어 그대로 `src/assets/ui`에 포함하고 화면의 1120×800 비율 아트보드에 차례로 합성했다.
- 카드 수와 위치가 바뀌어도 작동하도록 `칸 속 할 일 목록.png`, `화살표.png`, `현재선택테두리.png`, `투두에마우스올린거.png`, `완료버튼.png`, `우클릭체크시팝업.png`에서 반복 가능한 투명 조각을 추출해 실제 DOM 카드·버튼·메뉴의 배경으로 사용했다.
- 전체 화면 PNG를 단일 오버레이로 덮지 않았다. 그렇게 하면 새 카드, 긴 목록 스크롤, 드래그 이동, 모달이 원본 그림과 어긋나거나 가려지기 때문이다.
- 기본 1120×800 디자인 비율은 보존한다. 다른 창 비율에서는 레이아웃을 왜곡하지 않고 여백을 남긴다.

## 2026-09-26 추가·글자 레이어 반영

- `추가.png`의 원형 + 아이콘을 추출해 각 블록의 실제 카드 생성 버튼으로 사용했다.
- `글자.png`는 제목·시간대·상태 문구의 픽셀 글자 기준을 확인하는 레이어로 검토했다. 동적 날짜와 현재 시간은 같은 로컬 글꼴로 DOM에서 표시한다.
- 전체 화면 수정본에 맞춰 빈 블록은 중앙의 + 진입점을 유지하고, 하단의 + 버튼을 누르면 비저장 빈 카드가 목록 안에 나타난다. Enter로 유효한 이름을 입력했을 때만 실제 카드로 저장된다. Escape는 빈 카드를 닫는다.
- 카드 목록의 윗 여백을 원본 아트보드 기준 약 9px 늘려, 새 카드가 기존보다 아래에서 시작한다.

## 2026-09-26 고정 캔버스·첫 카드 구조

- 앱 작업면을 1120×800px 고정 크기로 맞췄다. 작은 창에서는 축소하지 않고 스크롤로 전체 작업면을 볼 수 있어, 원본 이미지와 DOM 요소의 좌표가 달라지지 않는다.
- `글자.png`를 배경·패널·테이프 위의 글자 레이어로 직접 합성했다. 제목, 구간명, 시간대 문구는 PNG의 정확한 위치와 형태를 유지한다.
- 각 시간대는 비저장 첫 카드 버튼을 한 장 기본으로 표시한다. 첫 카드 또는 그 아래의 원형 + 버튼을 누르면 해당 위치에 입력용 빈 카드가 열리고, Enter 이후에만 저장 카드가 된다. + 버튼은 고정 좌표가 아니라 마지막 생성 카드의 가로 중앙 아래를 따라간다.

## 구체적인 선택

- 한국어는 OS에 설치된 고딕 글꼴, 영문 소제목·숫자는 로컬 고정폭 글꼴. 외부 폰트 요청 없음.
- 카드 기본 최소 높이 36px, 연결 화살표 13px. 줄 바꿈이 필요한 현재 행동 버튼은 카드 높이가 늘어날 수 있음.
- 현재 행동: 분홍 바탕 + 실선 + 왼쪽 강조선 + ‘지금 하는 일’ 문구.
- 제안: 청회색 점선. 현재와 제안이 겹치면 바깥 점선을 추가하여 두 상태를 표시.
- 완료: 이름 주변 타원. 건너뜀: 취소선. 처리 규칙은 변경하지 않음.
- 실제 창의 최소화·닫기는 OS 제목 표시줄 사용. 장식용 가짜 창 버튼은 만들지 않음.
- 레퍼런스의 캐릭터·구도·그림은 사용하지 않음. 배경·프레임·색 균형과 픽셀 선의 느낌을 참고함.
- 애니메이션은 V7로 남김. 움직이는 배경이나 무작위 회전 없음.
